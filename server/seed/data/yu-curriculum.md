Orientation-year prerequisites (ORN 02R/02C … 05R/05C) are satisfied by all seeded students; encode them as `min_level`/none.
"90 CH" style prerequisites map to `min_credits`. Prereq syntax below: `[A, B]` = all required; `A|B` = either.

## Bachelor of Science in Software Engineering (BSE) – 142 CH

Year 1 / Sem 1 (19): CIS 103 Programming Fundamentals I (4); CHM 101 General Chemistry (4); MTH 106 Discrete Mathematics (3); ENG 101 English Essay Writing (3); ISL 101 Foundation of Islamic Culture (2); HSS Elective I (3)
Year 1 / Sem 2 (19): CIS 104 Programming Fundamentals II (4) [CIS 103]; PHY 103 Physics I (4); MTH 104 Calculus I (3); STT 103 Probability and Statistics (3); ARB 102 Communication Skills in Arabic (2); HSS Elective II (3)
Year 2 / Sem 1 (18): CIS 201 Fundamentals of Web Design (3) [CIS 103]; CIS 202 Data Structures (3) [CIS 104]; MIS 201 Introduction to Information Systems (3); PHY 203 Physics II (4) [PHY 103]; MTH 204 Calculus II (3) [MTH 104]; ISL 202 Financial Awareness (2)
Year 2 / Sem 2 (17): CIS 221 Introduction to Database Systems (3) [CIS 104]; SWE 202 Introduction to Software Engineering (3) [CIS 104]; NES 212 Data Communications & Computer Networks (3) [CIS 201]; MTH 304 Differential Equations (3) [MTH 204]; ENG 201 Technical Report Writing (3) [ENG 101]; ARB 202 Writing Skills in Arabic (2)
Year 3 / Sem 1 (18): CIS 304 Computer Architecture (3) [CIS 202]; CIS 386 Project Management (3) [SWE 202]; CIS 383 Cyber Security and Cryptography (3) [NES 212]; SWE 300 Software Process & Modelling (3) [SWE 202]; SWE 301 Software Requirements Engineering (3) [SWE 202]; MTH 301 Linear Algebra (3) [MTH 104]
Year 3 / Sem 2 (17): CIS 321 Operating Systems (3) [CIS 304]; CIS 381 Computer Ethics (2) [SWE 202]; CIS 316 Introduction to Artificial Intelligence (3) [SWE 202]; SWE 302 Software Architecture & Design (3) [SWE 202]; SWE 312 Software Construction & User Interface (3) [SWE 202]; SWE 322 Advanced Web Programming (3) [CIS 201, CIS 221]
Year 4 / Sem 1 (16): CIS 491 Graduation Project I (3) [90 CH, SWE 300, SWE 301, SWE 302]; CIS 443 Cloud Computing (3) [NES 212]; SWE 321 Advanced User Interface Design (3) [SWE 301]; SWE 411 Software Verification & Validation (3) [SWE 312]; SWE Elective I (3); SWE 410 Exit Exam Preparation (1) [90 CH, SWE 300, SWE 301, SWE 302]
Year 4 / Sem 2 (12): CIS 492 Graduation Project II (3) [CIS 491, SWE 411]; SWE 401 Software Quality Assurance (3) [SWE 301]; SWE Elective II (3); SWE Elective III (3); CSK 001 Career Skills (0)
Year 4 / Summer (6): CIS 490 Cooperative Assignment (6) [90 CH, SWE 410] (CSK 001 recommended before)

SWE electives (choose 3): SWE 402 Software Maintenance and Evolution [SWE 312]; SWE 413 Design Patterns [SWE 302]; SWE 414 Formal Methods in Software Engineering [SWE 202]; SWE 415 Software Usability Engineering [SWE 301]; CIS 222 Interactive Media [CIS 201]; SWE 412 Mobile Application Development [SWE 312]; CIS 416 Introduction to Machine Learning [MTH 301, STT 103, CIS 316]; NES 424 IoT Architectures, Protocols and Security [NES 212]; NES 481 Security Policies and Procedures [NES 212]; SWE 421 Game Development [SWE 312]; SWE 429 Selected Topics in Software Engineering [SWE 312]; MIS 432 Enterprise Systems [CIS 221] (all 3 CH)
HSS electives (choose 2, 3 CH each): SOS 102 Introduction to Social Science; PHL 101 Critical Thinking; PSY 101 Principles of Psychology; SOS 101 Saudi Heritage; FRE 106 Conversational French 1; CHI 107 Chinese Language; ENG 103 Introduction to English Literature

Degree requirement buckets for the audit (BSE): University core (ISL 101, ISL 202, ARB 102, ARB 202, ENG 101, ENG 201 = 14) · HSS electives (6) · Math & science (CHM 101, PHY 103, PHY 203, MTH 104, MTH 106, MTH 204, MTH 301, MTH 304, STT 103 = 30) · College core (CIS 103, CIS 104, CIS 201, CIS 202, CIS 221, MIS 201, NES 212, CIS 304, CIS 321, CIS 386, CIS 383, CIS 381, CIS 316, CIS 443, CIS 491, CIS 492, CIS 490 = 53) · Major core (SWE 202, SWE 300, SWE 301, SWE 302, SWE 312, SWE 322, SWE 321, SWE 411, SWE 401, SWE 410 = 30) · SWE electives (9) · CSK 001 (0). Total 142.

CNE electives (demo list, 3 CH): NES 424 IoT Architectures, Protocols and Security [CNE 200]; NES 481 Security Policies and Procedures [CNE 100]; CNE 420 Digital Forensics [CNE 307]; CNE 425 Ethical Hacking [CNE 307]
