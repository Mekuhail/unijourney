## Design specificity verdict

**LLM assessment:** the content is authored for Al Yamamah University; the composition is a generic dashboard.
YU-specific: attendance meters with the 15% / 25% policy, Sehhaty evidence, Sunday–Thursday week, Riyadh/Khobar map with
real footprints and step-free routes, the schedule-to-map handoff, gateway courses. Interchangeable: rows of big-number
tiles on every hub, icon-card grids with "Open" links, uppercase stat labels, soft-shadow cards everywhere.

**Deterministic scan:** source scan found 1 rule (`side-tab`, a false positive on the study load-bar capacity marker).
Rendered scans and in-page overlays confirmed: map search placeholder at 3.2:1 (light) / 4.5:1 (dark); prerequisite pool
count at 4.2:1 in dark mode; map pins drawn over labels (label de-cluttering ignores pins); aggressive title truncation in
Today's week list with no way to read the full title; tall prerequisite map next to an almost empty sidebar. Advisory:
every card pairs a 1px border with a wide soft shadow. False positives: brand fonts, map labels over footprints, the
segmented control flagged as a nested card, a closed legend flagged as occluded text.

## Priority issues

1. **[P1] Today counts lead to the wrong place and miss the urgent item.** The pending tile opened /approvals while the
   two items were hiring emails; unexcused absences with closing windows did not appear. Fix: point the tile at the
   list on Today, add excusable absences with days left. `/impeccable clarify`
2. **[P1] Arabic falls back to English where students act.** Server-built next actions, match reasons and policy notes
   are English-only. Fix: return message keys plus parameters and format on the client. `/impeccable harden`
3. **[P2] Starting an excuse is a hunt.** The "New request" button links to Attendance, sorted by course with 50
   sessions. Fix: lead with "absences you can still excuse". `/impeccable distill`
4. **[P2] Number tiles push work below the fold.** Fold numbers into sentences; drop hub cards that repeat navigation.
   `/impeccable layout`
5. **[P2] Mobile regressions from the touch-target rule.** Switches became 44 px circles, the registration text box was
   clipped, /campus overflowed at 375 px. `/impeccable adapt`
